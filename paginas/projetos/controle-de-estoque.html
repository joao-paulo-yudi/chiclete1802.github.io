Controle de EstoqueInventory Control

Programa para controle de estoque de uma loja de roupas, com integração do .NET ao banco de dados SQL Server e programação em C#. Possui ferramentas para pesquisar, adicionar e alterar pedidos e clientes, além de um guia de usuário para cada tela. Desenvolvido em 2023 como TCC do técnico em Desenvolvimento de Sistemas.Inventory software for a clothing store, written in C# with .NET talking to a SQL Server database. It has tools to search, add and edit orders and customers, plus a user guide for every screen. Built in 2023 as the capstone of my Systems Development technical degree.
